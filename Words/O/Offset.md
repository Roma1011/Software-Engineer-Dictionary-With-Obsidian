### Offset

**Offset** არის **მანძილი (დაშორება) რაიმე საწყისი წერტილიდან**. ის არ გვეუბნება, სად არის ელემენტი „საერთოდ", არამედ გვეუბნება, **რამდენით არის დაშორებული** ათვლის წერტილიდან.

მთავარი ფორმულა ყველა კონტექსტში ერთია:

```
მისამართი / პოზიცია = საწყისი წერტილი + offset
```

offset ჩვეულებრივ **ნულიდან** ითვლება: offset `0` თავად საწყისი წერტილია, offset `1` მისი მომდევნო ელემენტი.

**ახსნა:**
ტერმინი პროგრამირებაში ბევრგან გვხვდება, მაგრამ აზრი ყველგან ერთი და იგივეა: „საიდან ვითვლით" + „რამდენით წავიწიეთ".

#### 1. მეხსიერება და მასივები

მასივის ელემენტის მისამართი ასე ითვლება: **მასივის დასაწყისი + ინდექსი × ელემენტის ზომა**. აქ `ინდექსი × ზომა` არის offset ბაიტებში.

```
int[] numbers = { 10, 20, 30, 40 };   // თითო int = 4 ბაიტი

საწყისი მისამართი: 1000
numbers[0] → 1000 + 0  = 1000   (offset 0)
numbers[1] → 1000 + 4  = 1004   (offset 4)
numbers[2] → 1000 + 8  = 1008   (offset 8)
numbers[3] → 1000 + 12 = 1012   (offset 12)
```

სწორედ ამიტომ იწყება ინდექსი ნულიდან: პირველი ელემენტი დასაწყისიდან **0 ბაიტით** არის დაშორებული.

სტრუქტურის ველებსაც თავისი offset აქვს სტრუქტურის დასაწყისიდან. კომპილატორი ველებს შორის ზოგჯერ ცარიელ ბაიტებს ამატებს, რის გამოც ველის offset იცვლება (იხ. [[Padding]] და [[Alignment]]).

#### 2. ბუფერები და Stream-ები (.NET)

ბევრ .NET API-ს აქვს `offset` პარამეტრი. აქ ის ნიშნავს: **მასივის რომელი პოზიციიდან დავიწყოთ**.

```csharp
byte[] buffer = new byte[100];

// ჩაწერე buffer-ის 10-ე პოზიციიდან დაწყებული 20 ბაიტი
stream.Write(buffer, offset: 10, count: 20);
```

აქ ჩაიწერება `buffer[10]`-დან `buffer[29]`-მდე. `offset` ამბობს, საიდან დავიწყოთ, `count` კი რამდენი ავიღოთ.

#### 3. ფაილი

ფაილში offset არის **ბაიტების რაოდენობა ფაილის დასაწყისიდან**. `Seek` სწორედ offset-ით გადადის საჭირო ადგილას:

```csharp
using FileStream file = File.OpenRead("data.bin");

file.Seek(offset: 512, SeekOrigin.Begin);    // ფაილის დასაწყისიდან 512 ბაიტი
file.Seek(offset: -16, SeekOrigin.End);      // ფაილის ბოლოდან 16 ბაიტით უკან
file.Seek(offset: 8,   SeekOrigin.Current);  // მიმდინარე პოზიციიდან 8 ბაიტით წინ
```

`SeekOrigin` განსაზღვრავს **საწყის წერტილს**, offset კი **დაშორებას** მისგან. offset შეიძლება უარყოფითიც იყოს (უკან მოძრაობა).

#### 4. SQL და პაგინაცია

`OFFSET` ნიშნავს, **რამდენი ჩანაწერი გამოვტოვოთ** შედეგის დასაწყისიდან:

```sql
-- მესამე გვერდი, გვერდზე 10 ჩანაწერი
SELECT * FROM Orders
ORDER BY Id
OFFSET 20 ROWS              -- პირველი 20 გამოტოვე
FETCH NEXT 10 ROWS ONLY;    -- აიღე შემდეგი 10
```

იგივე LINQ-ში: `orders.OrderBy(o => o.Id).Skip(20).Take(10)`.

> [!WARNING]
> დიდ offset-ზე (მაგალითად, `OFFSET 1000000`) ბაზას მაინც უწევს ყველა გამოტოვებული ჩანაწერის გადათვლა, ამიტომ მოთხოვნა ნელდება. დიდი ცხრილებისთვის ხშირად იყენებენ **keyset (cursor) პაგინაციას**: `WHERE Id > @lastId` ბოლოს ნანახი გასაღებით.

#### 5. Kafka

Kafka-ში offset არის **შეტყობინების რიგითი ნომერი partition-ის შიგნით**. მომხმარებელი (consumer) ინახავს, რომელ offset-მდე წაიკითხა, რომ გადატვირთვის შემდეგ იქიდან გააგრძელოს.

```
Partition 0:  [0] [1] [2] [3] [4] [5] [6]
                            ↑
                  committed offset = 3
                  (0–3 დამუშავებულია, შემდეგი წასაკითხი არის 4)
```

#### 6. დრო: UTC offset

დროის ზონაში offset არის **სხვაობა UTC-სთან**. მაგალითად, თბილისის დრო არის `UTC+04:00`, ანუ offset = +4 საათი.

```csharp
DateTimeOffset now = DateTimeOffset.Now;
Console.WriteLine(now.Offset);   // 04:00:00 (თბილისში)
```

`DateTimeOffset` სწორედ ამიტომ ჰქვია: ის თარიღსაც ინახავს და ამ offset-საც.

---

|კონტექსტი|საწყისი წერტილი|offset ნიშნავს|
|---|---|---|
|**მეხსიერება / მასივი**|მასივის ან სტრუქტურის დასაწყისი|დაშორება ბაიტებში|
|**ბუფერი (`Write`, `Read`)**|მასივის 0-ე ელემენტი|საიდან დავიწყოთ კითხვა/ჩაწერა|
|**ფაილი (`Seek`)**|`Begin`, `Current` ან `End`|რამდენი ბაიტით გადავიდეთ|
|**SQL / პაგინაცია**|შედეგის პირველი ჩანაწერი|რამდენი ჩანაწერი გამოვტოვოთ|
|**Kafka**|partition-ის დასაწყისი|შეტყობინების რიგითი ნომერი|
|**დრო**|UTC|სხვაობა საათებში და წუთებში|

|ტერმინი|აღწერა|
|---|---|
|**Offset**|„რამდენით ვართ დაშორებული საწყისი წერტილიდან"|
|**Index vs Offset**|ინდექსი ითვლის ელემენტებს, offset ხშირად ითვლის ბაიტებს (მასივში offset = ინდექსი × ელემენტის ზომა)|
